# v1.1.0 自行验收说明

当前为待用户验证的预发布包。本次已按用户要求停止后续测试，以下是操作步骤，不代表已通过。

## 升级准备

1. 在托盘退出旧界面及后台，停止仍在运行旧版的额外计划任务。
2. 独立备份整个 `%LOCALAPPDATA%\Evenfall` 和旧 EXE，再把新版放到固定、本地、未加密目录。
3. 双击新版，设置里分别开启“未登录也执行任务”和“登录后启动托盘界面”。后台开关可能要求管理员授权；成功后应能继续操作主窗口。

## 核心场景

- 设置未来的任务，退出界面后重新打开，任务和截止时间应保持一致，不应出现数据目录占用警告。
- 重启后停留在 Windows 登录界面，检查后台是否按时执行；随后登录应出现托盘，双击打开界面连接原后台。
- 倒计时期间登录或解锁，显示剩余时间，取消与推迟应作用于后台同一次触发；仅登录不应延后目标时间。
- 停用任务后持续停用；午夜任务在前一天 23:59 取消，跳过紧接着的 00:00，下次为再下一天 00:00。退出界面、重开界面和重启后台分别检查持久化。
- 同时刻任务合并，不同时刻独立；取消或推迟一组不影响另一组。修改过程中若其他界面已更改任务，应拒绝旧草稿并允许重新载入。
- 关闭窗口进入托盘；“退出界面，后台继续”不能停止调度。“停止后台并退出”才结束当次后台。暂停全部须持久化，恢复不补执行错过任务。
- 断线、保存失败、权限不足应清晰提示，不应误报操作成功或启动第二个调度器。

## 专用环境项目

真实关机、未保存文档阻止普通关机、强制模式、真实注销／睡眠恢复、快速启动、异常恢复、电池供电、Windows 11 及多显示器缩放在合适的专用环境验证。不要把模拟结果当作这些项目通过。

若测试后暂不使用，请停止后台并按需关闭两个启动开关；单独退出界面不会停止任务。回退旧版前须停止并停用新版后台启动入口，再恢复升级前备份。

## 开发者可选模拟工具

- CTest：调度与 Windows 存储／时区。
- `tests/runtime_integration.py`：独立后台 IPC、权限限制、旧草稿、取消／推迟、保存失败等隔离模拟。
- `--client-test`：实际界面按钮与模拟后台联动。
- `tests/s4u_integration.py`：管理员权限下创建临时模拟 S4U 任务，检查跨会话连接及异常重启，完成后清理。它不执行真实关机。
- `scripts/qa.py`：集成检查、截图和界面／后台资源样本。

本次交付不再运行这些工具，后续需要时由用户或维护者显式运行。
