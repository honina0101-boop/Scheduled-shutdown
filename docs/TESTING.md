# 测试说明

自动测试和界面自检始终使用模拟关机，不会调用真实关机，也不会修改 Windows 启动项。测试数据与用户数据分开。

## 自动覆盖

- 一次、每日、工作日、周末、自选星期、跨午夜、邻近任务。
- 同时刻合并、取消整组、单独修改／停用合并组中的任务。
- 相距 30 秒的任务独立提前提醒、切换、取消／推迟及后台到期提交，不互相延后。
- 最后一毫秒取消、保存并重新加载、改名不恢复取消状态。
- 推迟保留下一次重复计划及历史记录。
- 软件重启、睡眠错过、暂停／恢复、系统时钟前进／回退。
- Windows Pacific 时区 2026 年夏令时不存在与重复的时刻。
- 中文保存、原子替换、备份恢复、结构验证、保存失败停止执行。
- 任务编辑、无效日期／时间／倒计时、键盘保存、主题和提醒预览。
- 提醒连接实际调度状态，模拟执行只提交一次，保存失败绝不调用执行器。
- 同一绘图代码导出 100%／150%／200%，并人工查看主要界面图。

## 资源验证

scripts/qa.py 先跑测试，再运行隔离的模拟进程，测量冷启动直接到托盘、显示窗口后隐藏到托盘的工作集、私有内存、峰值和 CPU 时间。同时检查 EXE 大小、SHA-256、PE 导入 DLL 和真实启动项保持不变。

结果写到 build/qa/report.json 和 docs/QA-REPORT.md。这是当前机器样本，不代表所有显卡驱动和系统版本。

## 真机验证

以下项目需要合适的测试电脑／虚拟机，自动化测试不能替代：

1. 在 Windows 10、Windows 11 分别运行发布 EXE，检查字体、托盘和编辑。
2. 独立测试环境安排未来两分钟任务，检查 60 秒提醒，取消并重开后不执行。
3. 保留未保存文档，分别验证普通关机被阻止与强制关机关闭。
4. 重复任务取消一次后，下一个选中日期继续执行。
5. 实际睡眠跨过目标时间后跳过；目标前不足一分钟恢复后完整提醒。
6. 系统缩放 100%／150%／200%，在不同 DPI 的两块显示器间移动窗口。
7. 主屏任务栏位于底部／左侧／右侧时，提醒避开任务栏且不抢焦点。
8. 自启动开关更改后重新登录；检查任务管理器禁用启动项的行为。
9. 锁屏时继续计时，解锁后提醒可操作；退出软件后停止调度。

本环境未实测的项目会在验证报告中标注。
